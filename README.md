## 3. Project selection:
Movie & TV Tracker.

## 4. Project description:
Our project will include a list of movies and TV shows. Each movie and show will be clickable and when clicked a user will be redirected to a page that is about that movie or show. The pages for each show and movie will include details such as genre, synopsys, and rating. 

## 5. Two functional tabs:
The first tab will include the list movies and TV shows. Selecting a movie or show will open the second tab which will include the movie/TV show details femiliarizing the user with what they selected. 

## 6. Technology:
The Supabase will include the list of movies and TV shows with all their details.  The android app and website will use the data from the Supbase to create the display the user will see and enable the user to navigate the different tabs and expose our Supabase data.
